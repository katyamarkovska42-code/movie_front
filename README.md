# MovieGuide Frontend

Frontend частина вебзастосунку **MovieGride** — каталогу фільмів, який взаємодіє з Django REST API.

## Основні можливості

- Перегляд каталогу фільмів.
- Пошук фільмів за назвою.
- Фільтрація за роком випуску.
- Сортування за назвою, роком випуску та рейтингом.
- Відображення інформації про фільм: назва, режисер, рік, рейтинг та опис.
- Реєстрація нових користувачів.
- Авторизація користувачів.
- Збереження JWT access та refresh tokens у Local Storage.
- Автоматичне оновлення access token за допомогою refresh token.
- Особиста сторінка для авторизованих користувачів.
- Вихід з облікового запису.

## Взаємодія з Backend

Адреса Backend:

http://127.0.0.1:8000

Базова адреса API:

http://127.0.0.1:8000/api/

Для авторизації використовуються такі endpoints:

| Метод | Endpoint | Призначення |
|---|---|---|
| POST | `/api/auth/register/` | Реєстрація |
| POST | `/api/auth/login/` | Вхід |
| POST | `/api/auth/refresh/` | Оновлення access token |
| POST | `/api/auth/logout/` | Вихід |

Після успішного входу access та refresh tokens зберігаються в Local Storage браузера.

## Як запустити проєкт

1. Клонувати репозиторій Frontend.
2. Запустити Backend MovieGuide.
3. Переконатися, що API доступне за адресою http://127.0.0.1:8000/api/.
4. Відкрити папку Frontend у VS Code.
5. Запустити `index.html` за допомогою розширення Live Server.

Frontend відкривається за локальною адресою, яку надає Live Server.
